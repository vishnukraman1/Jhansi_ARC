# 0001: Hybrid Vector Drafting and Exploded Spatial Workbench

We decided to pair each architectural project with a dual technical evidence workbench: an interactive 2D SVG/DXF vector engine with live room-zone polygon HUDs and layer toggling, alongside a procedural 3D Three.js massing study engine with vertical assembly separation sliders. This ensures the portfolio demonstrates rigorous structural and BIM proficiency to architectural juries and patrons directly in the browser without requiring external CAD software.
